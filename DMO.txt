Dungeon Master Online (DMO)

This will be an online dungeon master and DnD campaign runner potentially ran by ai. The users will be able to log in and build a character sheet and store it with other character sheets. The users will be able to join a room with a unique room code and join their friends or play solo. from there they will be able input a DnD campaign and the DM or ai DM will run the game. The users will have all the game info at their access and will have inventories and other game features like health, mana, and other game features. The users will have options on how they want their game to run. If its ran by ai they'll be able to tell the DM how to act and interact with the users. All the user data will be stored in a database so their info like character sheets and inventories or anything else can be stored for later use and so the data wont be lost.
